Statistics for Insurance · Bracketing CLT

Bracketing Exam Checklist

Six steps for any “show this process converges” question. Answer the question in each step, write the line, move on.

  1. 1

    Find $f_t$

    What is inside the sum?

    Write the estimator as $\frac1n\sum_i(\dots)$. The thing inside, as a function of one observation $z$, is $f_t(z)$. The index $t$ is whatever the statement must hold uniformly over.

    • Ratio, log, inverse…? Find the average(s) inside, do steps 2–5 for each, and use the map in step 6.
    • Rate not $\sqrt n$ (e.g. $\sqrt{nh}$)? Put the extra factor into $f$. Then $f$ depends on $n$ → Theorem 1.20.
  2. 2

    Envelope

    For fixed $z$, how big can $|f_t(z)|$ get over all $t$?

    Call it $F(z)$ and check $\E F(Z)^2\lt\infty$.

  3. 3

    Draw it

    Fix $z$. What does $t\mapsto f_t(z)$ look like?

    • It jumps (indicators) → type A
    • It is a monotone ramp with bounded slope → type B
    • It wiggles (not monotone) but has bounded slope → type C
  4. 4

    One cell $[a,b)$: bracket, width, grid

    What are the smallest and largest values of $f_t$ on the cell, and what is $\E[(u-l)^2]$?

    TypeBracketWidth²GridCount $N$
    A$l,u=f$ at the two ends$P(a\lt Z\lt b)$
    (or $\E[g(Z)^2;\,a\lt Z\lt b]$)    		each cell mass $\varepsilon^2$ (quantiles)$\approx1/\varepsilon^2$
    B$l,u=f$ at the two ends$\le\text{slope}^2\,(b-a)^2$equal spacing $\delta=\varepsilon/\text{slope}$$\approx$ length$/\delta$
    C$f_{t_j}\pm\delta M(z)$, $M\ge|\partial_tf|$$(2\delta\|M\|)^2$$\delta=\varepsilon/(2\|M\|)$$\approx$ length$\cdot\|M\|/\varepsilon$
    Index goes to $\infty$ (type B or C)? Add one tail bracket $[0,\ \text{envelope beyond }D]$ and choose $D$ so its width is $\le\varepsilon$.
  5. 5

    Conclude Donsker

    Write $N\le C\varepsilon^{-V}$. Then

    $$\int_0^1\sqrt{\log N}\,d\varepsilon\le\sqrt{\log C}+\tfrac{\sqrt{\pi V}}{2}\lt\infty,$$

    so the class is Donsker by Theorem 1.19.

  6. 6

    Limit

    Covariance $=\E[f_sf_t]-\E f_s\,\E f_t$. If there was a map in step 1: differentiate the map and apply the derivative to the limit process (functional δ-method, Theorem 1.17).

Mini-example

Question. Show that the empirical Laplace transform $\frac1n\sum_ie^{-\theta Z_i}$, $\theta\in[1,2]$, $Z\ge0$, satisfies a functional CLT.

  1. $f_\theta(z)=e^{-\theta z}$, index $\theta\in[1,2]$.
  2. Envelope $F\equiv1$ (since $z,\theta\ge0$).
  3. $\theta\mapsto e^{-\theta z}$ is decreasing, slope $ze^{-\theta z}\le ze^{-z}\le1/e$ → type B.
  4. On $[a,b]$: bracket $[e^{-bz},e^{-az}]$, width $\le(b-a)/e$. Spacing $\delta=e\varepsilon$ → $N\le1/(e\varepsilon)+1\le2/\varepsilon$.
  5. $C=2$, $V=1$ → Donsker.
  6. Covariance $\E e^{-(s+t)Z}-\E e^{-sZ}\,\E e^{-tZ}$.

20 exam-style solutions

Each example is written as you would hand it in. Two facts are used throughout, so prove them once and cite them as (Q) and (E). Notation: $\|\cdot\|=\|\cdot\|_{L_2(P)}$, $m_2=\E Z^2$, $\mathcal F$ the class, $F$ the envelope.

(Q) Quantile grid. Let $\mu$ be a finite measure on $\R$ with total mass $m$, and let $\eta>0$. Put $k=\lfloor m/\eta\rfloor+1$, $t_0=-\infty$, $t_k=\infty$ and $t_j=\inf\{t:\mu(-\infty,t]\ge j\eta\}$ for $0\lt j\lt k$. Then $\mu\big((t_{j-1},t_j)\big)\le\eta$ for all $j$, using $k\le m/\eta+1$ cells.

Proof. For $t\lt t_j$, $\mu(-\infty,t]\lt j\eta$; letting $t\uparrow t_j$ gives $\mu(-\infty,t_j)\le j\eta$. Right-continuity gives $\mu(-\infty,t_{j-1}]\ge(j-1)\eta$. Subtract: $\mu((t_{j-1},t_j))\le\eta$. For the last cell, $m-\mu(-\infty,t_{k-1}]\le m-(k-1)\eta\lt\eta$ since $(k-1)\eta>m-\eta$. ∎

(E) Entropy bound. If $\Nb(\varepsilon)\le C\varepsilon^{-V}$ on $(0,1)$ with $C\ge1$, then $$\int_0^1\sqrt{\log\Nb(\varepsilon)}\,d\varepsilon\le\sqrt{\log C}+\sqrt V\int_0^1\sqrt{\log(1/\varepsilon)}\,d\varepsilon=\sqrt{\log C}+\sqrt V\,\Gamma(\tfrac32)=\sqrt{\log C}+\tfrac{\sqrt{\pi V}}2\lt\infty,$$ using $\sqrt{a+b}\le\sqrt a+\sqrt b$ and the substitution $\varepsilon=e^{-x}$. The integrand is integrable, so also $\int_0^{\delta_n}\sqrt{\log\Nb}\,d\varepsilon\to0$ for $\delta_n\to0$. ∎

Only $\varepsilon\in(0,1)$ matters; there, bounds like $\varepsilon^{-2}+1\le2\varepsilon^{-2}$ turn counts into the form $C\varepsilon^{-V}$.

01

Empirical cdf

A

Let $Z_1,Z_2,\dots$ be iid with arbitrary cdf $F$. Show that $\sqrt n(F^{(n)}-F)\overset d\to\mathbb B\circ F$ in $\ell^\infty(\R)$.

Class. $F^{(n)}(t)=\Pn f_t$ with $f_t(z)=\ind(z\le t)$, so $\sqrt n(F^{(n)}(t)-F(t))=\Gn f_t$, $\mathcal F=\{f_t:t\in\R\}$. Envelope $F\equiv1$, $\E F^2=1\lt\infty$.

Brackets. Fix $\varepsilon\in(0,1)$ and take the grid of (Q) with $\mu=P_Z$, $\eta=\varepsilon^2$: $k\le\varepsilon^{-2}+1$ cells with $F(t_j-)-F(t_{j-1})\le\varepsilon^2$. For $t\in[t_{j-1},t_j)$, since $t\mapsto\ind(z\le t)$ is non-decreasing, $$l_j=\ind(z\le t_{j-1})\le f_t(z)\le\ind(z\lt t_j)=u_j .$$ Now $u_j-l_j=\ind(t_{j-1}\lt z\lt t_j)\in\{0,1\}$, so $(u_j-l_j)^2=u_j-l_j$ and $$\|u_j-l_j\|^2=P(t_{j-1}\lt Z\lt t_j)=F(t_j-)-F(t_{j-1})\le\varepsilon^2 .$$

Count. $\Nb(\varepsilon,\mathcal F,L_2(P))\le k\le\varepsilon^{-2}+1\le2\varepsilon^{-2}$. By (E) with $C=2$, $V=2$: $\Jb\le\sqrt{\log2}+\sqrt{\pi/2}\lt\infty$. So $\mathcal F$ is $P$-Donsker (Thm 1.19).

Limit. $\Cov(\mathbb Gf_s,\mathbb Gf_t)=\E[\ind(Z\le s)\ind(Z\le t)]-F(s)F(t)=F(s\wedge t)-F(s)F(t)$. Since $F$ is non-decreasing, $F(s\wedge t)=F(s)\wedge F(t)$, which is the covariance of $\mathbb B(F(s)),\mathbb B(F(t))$ (as $\Cov(\mathbb B(u),\mathbb B(v))=u\wedge v-uv$). Centred Gaussian processes with equal covariances have equal laws, so the limit is $\mathbb B\circ F$. ∎

02

Cumulative hazard

Amap

Let $\tau$ satisfy $F(\tau)\lt1$ and $\Lambda^{(n)}=-\log(1-F^{(n)})$. Show that $\sqrt n(\Lambda^{(n)}-\Lambda)$ converges in $\ell^\infty([0,\tau])$ and find the covariance.

Class. $\Lambda^{(n)}=\phi(F^{(n)})$ with $\phi(h)(t)=-\log(1-h(t))$. The only average is $F^{(n)}$, so the class is that of 01. By 01 and Lemma 1.6, $\sqrt n(F^{(n)}-F)\overset d\to\mathbb B\circ F$ in $\ell^\infty([0,\tau])$.

Map. Let $c=\tfrac{1+F(\tau)}2\lt1$ and $D_\phi=\{h:-1\lt h\lt c\text{ on }[0,\tau]\}$. On $(-1,c)$, $\varphi(x)=-\log(1-x)$ has $\varphi'(x)=\frac1{1-x}\le\frac1{1-c}$ and $\varphi''(x)=\frac1{(1-x)^2}\le\frac1{(1-c)^2}$. So $\varphi'$ is bounded and uniformly continuous, and Lemma 1.10(2) gives Hadamard differentiability at $F\in D_\phi$ with $$\phi'_F(h)(t)=\frac{h(t)}{1-F(t)} .$$ Also $F^{(n)}(\tau)\to F(\tau)\lt c$ a.s., so $P(F^{(n)}\in D_\phi)\to1$.

Limit. By Thm 1.17, $\sqrt n(\Lambda^{(n)}-\Lambda)\overset d\to\dfrac{\mathbb B(F(t))}{1-F(t)}$ in $\ell^\infty([0,\tau])$. For $s\le t$: $$\Cov=\frac{F(s)-F(s)F(t)}{(1-F(s))(1-F(t))}=\frac{F(s)(1-F(t))}{(1-F(s))(1-F(t))}=\frac{F(s\wedge t)}{1-F(s\wedge t)} .$$ At $s=t$ this is $F(t)/(1-F(t))$, agreeing with Thm 1.12. ∎

03

Quantile process (VaR)

Amap

Let $0\lt p\lt q\lt1$ and let $F$ be $C^1$ with $f=F'>0$ on $[a,b]=[F^{-1}(p)-\eta,F^{-1}(q)+\eta]$. Show that $\sqrt n\big((F^{(n)})^{-1}-F^{-1}\big)$ converges in $\ell^\infty([p,q])$, and give the limit for $\widehat{\mathrm{VaR}}_\alpha$.

Class. $(F^{(n)})^{-1}=\phi(F^{(n)})$ with $\phi$ the inverse map; the average is $F^{(n)}$, class of 01. By 01 and Lemma 1.6, $\sqrt n(F^{(n)}-F)\overset d\to\mathbb B\circ F$ in $\ell^\infty([a,b])$. The limit has continuous paths ($\mathbb B$ and $F$ continuous on $[a,b]$), so it lies in $C[a,b]$.

Map. By Lemma 1.10(1)(i), $\phi$ is Hadamard differentiable at $F$ tangentially to $C[a,b]$, with $\phi'_F(h)=-(h/f)\circ F^{-1}$.

Limit. By Thm 1.17, and $F(F^{-1}(u))=u$ for continuous $F$: $$\sqrt n\big((F^{(n)})^{-1}-F^{-1}\big)(u)\overset d\to-\frac{\mathbb B(u)}{f(q_u)},\qquad q_u=F^{-1}(u),$$ $$\Cov=\frac{u\wedge v-uv}{f(q_u)f(q_v)} .$$ In particular, for $\alpha\in[p,q]$: $\sqrt n(\widehat{\mathrm{VaR}}_\alpha-\mathrm{VaR}_\alpha)\overset d\to N\big(0,\alpha(1-\alpha)/f(q_\alpha)^2\big)$. ∎

04

Mean excess function

Amap

Let $Z\ge0$ with $m_2\lt\infty$ and $F(U)\lt1$. Prove a functional CLT for $e_n(u)$ on $[0,U]$.

Class. $e_n(u)=\Pn f_u/\Pn g_u-u$ with $f_u=z\ind(z>u)$, $g_u=\ind(z>u)$, $u\in[0,U]$. Class $\mathcal F\cup\mathcal G$, envelope $z+1$, $\E(Z+1)^2\le2m_2+2\lt\infty$.

Brackets for $\mathcal F$. Let $\mu(A)=\E[Z^2\ind(Z\in A)]$ (mass $m_2$). Use (Q) with $\eta=\varepsilon^2$, cut at $U$: $0=a_0\lt\dots\lt a_k=U$, $k\le m_2/\varepsilon^2+1$, $\mu((a_{j-1},a_j))\le\varepsilon^2$. For $u\in[a_{j-1},a_j)$: if $z\ge a_j$ then $z>u$; if $z>u$ then $z>a_{j-1}$. Hence $$l_j=z\ind(z\ge a_j)\le f_u\le z\ind(z>a_{j-1})=u_j,\qquad \|u_j-l_j\|^2=\E[Z^2\ind(a_{j-1}\lt Z\lt a_j)]\le\varepsilon^2 .$$ Add the singleton $[f_U,f_U]$: $\Nb(\mathcal F)\le m_2/\varepsilon^2+2$.

Brackets for $\mathcal G$. $g_u=1-\ind(z\le u)$; the brackets of 01 give $\Nb(\mathcal G)\le\varepsilon^{-2}+2$.

Count. Union: $\Nb\le(m_2+1)\varepsilon^{-2}+4\le(m_2+5)\varepsilon^{-2}$. By (E), $\Jb\le\sqrt{\log(m_2+5)}+\sqrt\pi$, so $\mathcal F\cup\mathcal G$ is Donsker. Hence $\sqrt n(\Pn f_\cdot-A,\Pn g_\cdot-B)\overset d\to(\mathbb Gf_\cdot,\mathbb Gg_\cdot)$ jointly, with $A(u)=Pf_u$, $B(u)=1-F(u)\ge c:=1-F(U)>0$.

Map. $\phi(A,B)=A/B-\mathrm{id}$ on $\{B\ge c/2\}$. For $t_n\to0$, $h_{in}\to h_i$ uniformly: $$\frac1{t_n}\Big(\frac{A+t_nh_{1n}}{B+t_nh_{2n}}-\frac AB\Big)=\frac{h_{1n}B-Ah_{2n}}{B(B+t_nh_{2n})}\to\frac{h_1}B-\frac{Ah_2}{B^2}$$ uniformly, since $B(B+t_nh_{2n})\ge c^2/2$ eventually and $A\le\E Z$.

Limit. Thm 1.17 and linearity of $\mathbb G$, with $m(u)=A/B=e_F(u)+u$: $$\sqrt n(e_n-e_F)\overset d\to\frac{\mathbb G(h_u)}{1-F(u)},\qquad h_u=(z-m(u))\ind(z>u),\quad Ph_u=A-mB=0 ,$$ $$\Cov(s,t)=\frac{\E[(Z-m(s))(Z-m(t))\ind(Z>s\vee t)]}{(1-F(s))(1-F(t))} .$$ At $s=t=u$: $\E[(Z-m)^2;Z>u]=(1-F(u))\Var(Z\mid Z>u)=(1-F(u))(e^{(2)}_F-e_F^2)$, giving variance $\dfrac{e^{(2)}_F-e_F^2}{1-F(u)}$, as in Thm 1.11. ∎

05

Truncated first moment

A

Let $Z\ge0$, $m_2\lt\infty$, $M(t)=\E[Z\ind(Z\le t)]$. Show $\sqrt n(M_n-M)$ converges in $\ell^\infty(\R)$, where $M_n(t)=\Pn[z\ind(z\le t)]$.

Class. $f_t=z\ind(z\le t)$, $t\in\R$. Envelope $z$, $\E Z^2=m_2\lt\infty$.

Brackets. $z\ge0$, so $t\mapsto f_t(z)$ is non-decreasing (jump of height $z$ at $t=z$). Let $\mu(A)=\E[Z^2\ind(Z\in A)]$ and take the (Q) grid with $\eta=\varepsilon^2$. For $t\in[t_{j-1},t_j)$: $$l_j=z\ind(z\le t_{j-1})\le f_t\le z\ind(z\lt t_j)=u_j,\qquad\|u_j-l_j\|^2=\E[Z^2\ind(t_{j-1}\lt Z\lt t_j)]\le\varepsilon^2 .$$

Count. $\Nb\le m_2/\varepsilon^2+1\le(m_2+1)\varepsilon^{-2}$. By (E), $\Jb\le\sqrt{\log(m_2+1)}+\sqrt\pi$: Donsker.

Limit. $f_sf_t=z^2\ind(z\le s\wedge t)$, so $\Cov(\mathbb G(s),\mathbb G(t))=\E[Z^2\ind(Z\le s\wedge t)]-M(s)M(t)$. ∎

06

Signed weight, not monotone

A

Let $Z$ be real-valued with $m_2\lt\infty$. Show $\{z\ind(z\le t):t\in\R\}$ is Donsker.

Class. $f_t=z\ind(z\le t)$, envelope $|z|$, $\E Z^2\lt\infty$.

Shape. The jump at $t=z$ has height $z$, which may be negative, so $f_t$ is not monotone in $t$. Use a bracket centred at the left endpoint.

Brackets. $\mu(A)=\E[Z^2\ind(Z\in A)]$; (Q) with $\eta=\varepsilon^2/4$: $k\le4m_2/\varepsilon^2+1$. For $t\in[t_{j-1},t_j)$, $f_t-f_{t_{j-1}}=z\ind(t_{j-1}\lt z\le t)$, so $$|f_t-f_{t_{j-1}}|\le|z|\ind(t_{j-1}\lt z\lt t_j)=:r_j,\qquad f_t\in[f_{t_{j-1}}-r_j,\ f_{t_{j-1}}+r_j] ,$$ $$\|2r_j\|^2=4\,\E[Z^2\ind(t_{j-1}\lt Z\lt t_j)]\le4\cdot\varepsilon^2/4=\varepsilon^2 .$$

Count. $\Nb\le(4m_2+1)\varepsilon^{-2}$; (E) gives $\Jb\le\sqrt{\log(4m_2+1)}+\sqrt\pi$: Donsker.

Limit. $\Cov=\E[Z^2\ind(Z\le s\wedge t)]-M(s)M(t)$, $M(t)=\E[Z\ind(Z\le t)]$. (Alternative: write $z=z^+-z^-$, apply 05 to each part, and use the sum rule.) ∎

07

Stop-loss premium

B

Let $Z\ge0$ with $m_p=\E Z^p\lt\infty$ for some $p>2$, and $\pi_n(d)=\Pn(z-d)_+$. Show $\sqrt n(\pi_n-\pi)$ converges in $\ell^\infty([0,\infty))$.

Class. $f_d=(z-d)_+$, $d\ge0$. Envelope $\sup_d(z-d)_+=z$; $\E Z^2\le(\E Z^p)^{2/p}\lt\infty$ (Lyapunov).

Shape. $d\mapsto(z-d)_+$ is non-increasing, and for $d\le d'$: $0\le(z-d)_+-(z-d')_+\le d'-d$, because $x\mapsto x_+$ is 1-Lipschitz.

Brackets on $[0,D]$. $d_j=j\varepsilon$, $j=0,\dots,J=\lceil D/\varepsilon\rceil$. For $d\in[d_{j-1},d_j]$: $(z-d_j)_+\le f_d\le(z-d_{j-1})_+$, and $0\le u_j-l_j\le\varepsilon$ pointwise, so $\|u_j-l_j\|\le\varepsilon$.

Tail bracket. For $d\ge D$: $0\le f_d\le(z-D)_+$. On $\{z>D\}$, $z^2=z^pz^{2-p}\le z^pD^{2-p}$, so $$\|(Z-D)_+\|^2\le\E[Z^2\ind(Z>D)]\le m_pD^{2-p}\le\varepsilon^2\iff D=\Big(\frac{m_p}{\varepsilon^2}\Big)^{1/(p-2)} .$$

Count. $\Nb\le J+1\le\frac D\varepsilon+2=m_p^{1/(p-2)}\varepsilon^{-1-\frac2{p-2}}+2\le\big(m_p^{1/(p-2)}+2\big)\varepsilon^{-p/(p-2)}$. By (E) with $V=p/(p-2)$: Donsker.

Limit. $\Cov(\mathbb G(s),\mathbb G(t))=\E[(Z-s)_+(Z-t)_+]-\pi(s)\pi(t)$. ∎

08

Excess-of-loss layer

B

Let $Z\ge0$ with $\E Z\lt\infty$ and a limit $L>0$. Show $\{f_d=\min((z-d)_+,L):d\ge0\}$ is Donsker.

Class. $f_d=\min((z-d)_+,L)$. Envelope $L$, so $\E F^2=L^2\lt\infty$ — no second moment of $Z$ needed.

Shape. $f_d$ is a composition of the 1-Lipschitz, non-decreasing maps $x\mapsto x_+$ and $x\mapsto\min(x,L)$ applied to $z-d$. So it is non-increasing in $d$ with $0\le f_d-f_{d'}\le d'-d$ for $d\le d'$.

Brackets. On $[0,D]$ with $d_j=j\varepsilon$: $[f_{d_j},f_{d_{j-1}}]$, width $\le\varepsilon$. Tail $d\ge D$: $f_d=0$ unless $z>d\ge D$, so $0\le f_d\le L\ind(z>D)$, and by Markov $$\|L\ind(Z>D)\|^2=L^2P(Z>D)\le\frac{L^2\E Z}{D}\le\varepsilon^2\iff D=\frac{L^2\E Z}{\varepsilon^2} .$$

Count. $\Nb\le D/\varepsilon+2=L^2\E Z\,\varepsilon^{-3}+2\le(L^2\E Z+2)\varepsilon^{-3}$. (E) with $V=3$: Donsker.

Limit. $\Cov=\E[f_s(Z)f_t(Z)]-\E f_s(Z)\,\E f_t(Z)$. Compared with 07, capping the payout replaces the moment condition $p>2$ by $\E Z\lt\infty$. ∎

09

Limited expected value

B

Let $Z\ge0$ (no moment assumption) and $L_n(t)=\Pn\min(z,t)$. Show $\sqrt n(L_n-L)$ converges in $\ell^\infty([0,\tau])$.

Class. $f_t=\min(z,t)$, $t\in[0,\tau]$. Envelope $\sup_t\min(z,t)=\min(z,\tau)\le\tau$.

Shape. Non-decreasing in $t$, and $0\le\min(z,t')-\min(z,t)\le t'-t$ for $t\le t'$.

Brackets. $t_j=j\varepsilon$, $j=0,\dots,J=\lceil\tau/\varepsilon\rceil$ (last point capped at $\tau$). For $t\in[t_{j-1},t_j]$: $[\min(z,t_{j-1}),\min(z,t_j)]$, width $\le\varepsilon$.

Count. $\Nb\le\tau/\varepsilon+1\le(\tau+1)\varepsilon^{-1}$. (E) with $V=1$: Donsker.

Limit. $\Cov=\E[\min(Z,s)\min(Z,t)]-L(s)L(t)$. ∎

10

Laplace transform

B

Let $Z\ge0$ and $0\lt a\lt b$. Show $\sqrt n(\mathcal L_n-\mathcal L)$ converges in $\ell^\infty([a,b])$, where $\mathcal L_n(\theta)=\Pn e^{-\theta z}$.

Class. $f_\theta=e^{-\theta z}$, $\theta\in[a,b]$. Envelope 1.

Shape. Non-increasing in $\theta$. For $\theta\lt\theta'$: $$0\le e^{-\theta z}-e^{-\theta'z}=\int_\theta^{\theta'}ze^{-sz}\,ds\le(\theta'-\theta)\,ze^{-az}\le\frac{\theta'-\theta}{ae},$$ since $z\mapsto ze^{-az}$ is maximised at $z=1/a$ with value $1/(ae)$.

Brackets. $\theta_j=a+j\delta$ with $\delta=ae\,\varepsilon$; on $[\theta_{j-1},\theta_j]$: $[e^{-\theta_jz},e^{-\theta_{j-1}z}]$, width $\le\delta/(ae)=\varepsilon$.

Count. $\Nb\le\lceil(b-a)/(ae\varepsilon)\rceil\le\big(\tfrac{b-a}{ae}+1\big)\varepsilon^{-1}$. (E), $V=1$: Donsker.

Limit. $\Cov=\mathcal L(s+t)-\mathcal L(s)\mathcal L(t)$. ∎

11

Power moments

B

Let $Z\ge1$ with $\E(Z\log Z)^2\lt\infty$. Show $\{z^\theta:\theta\in[0,1]\}$ is Donsker.

Class. $f_\theta=z^\theta$. For $z\ge1$, $z^\theta\le z$, so envelope $z$. $\E Z^2\lt\infty$: on $\{Z\ge e\}$, $Z\le Z\log Z$; on $\{Z\lt e\}$, $Z\le e$.

Shape. Non-decreasing in $\theta$ (as $z\ge1$), and for $\theta\lt\theta'$: $$0\le z^{\theta'}-z^\theta=\int_\theta^{\theta'}z^s\log z\,ds\le(\theta'-\theta)\,z\log z=:(\theta'-\theta)M(z).$$ The slope bound $M$ is random, so the width is $\delta\|M\|$.

Brackets. $\theta_j=j\delta$ with $\delta=\varepsilon/\|Z\log Z\|$; $[z^{\theta_{j-1}},z^{\theta_j}]$ has width $\le\delta\|M\|=\varepsilon$.

Count. $\Nb\le\lceil1/\delta\rceil\le(\|Z\log Z\|+1)\varepsilon^{-1}$. (E), $V=1$: Donsker.

Limit. $\Cov(\mathbb G(s),\mathbb G(t))=\E Z^{s+t}-\E Z^s\,\E Z^t$. ∎

12

Huber score

B

Let $\psi_c(x)=\max(-c,\min(c,x))$ and $K>0$. Show $\{\psi_c(z-\theta):\theta\in[-K,K]\}$ is Donsker, with no moment assumption on $Z$.

Class. $f_\theta=\psi_c(z-\theta)$, envelope $c$.

Shape. $\psi_c$ is non-decreasing and 1-Lipschitz, so $\theta\mapsto f_\theta$ is non-increasing and $0\le f_\theta-f_{\theta'}\le\theta'-\theta$ for $\theta\le\theta'$.

Brackets. $\theta_j=-K+j\varepsilon$; on $[\theta_{j-1},\theta_j]$: $[\psi_c(z-\theta_j),\psi_c(z-\theta_{j-1})]$, width $\le\varepsilon$.

Count. $\Nb\le\lceil2K/\varepsilon\rceil\le(2K+1)\varepsilon^{-1}$. (E), $V=1$: Donsker.

Limit. $\Cov=\E[\psi_c(Z-s)\psi_c(Z-t)]-\E\psi_c(Z-s)\,\E\psi_c(Z-t)$. This is the uniformity behind consistency and normality of the Huber M-estimator. ∎

13

Characteristic function

C

Let $m_2\lt\infty$ and $\varphi_n(t)=\Pn e^{itz}$. Show $\sqrt n(\varphi_n-\varphi)\overset d\to\mathbb G$ in $\ell^\infty([-T,T])$ and find the covariance.

Class. $e^{itz}$ is complex, so use the real classes $\mathcal C=\{\cos(tz)\}$, $\mathcal S=\{\sin(tz)\}$, $t\in[-T,T]$; $\Gn e^{it\cdot}=\Gn\cos_t+i\,\Gn\sin_t$. Envelope 1.

Shape. Not monotone in $t$. Mean value theorem: $|\cos(tz)-\cos(sz)|=|z\sin(\xi z)|\,|t-s|\le|z|\,|t-s|$, and likewise for $\sin$. So $M(z)=|z|$.

Brackets. $\delta=\varepsilon/(2\|Z\|)$, centres $t_j=-T+(2j-1)\delta$, $j=1,\dots,J=\lceil T/\delta\rceil$, so the intervals $[t_j-\delta,t_j+\delta]$ cover $[-T,T]$. For $|t-t_j|\le\delta$: $$\cos(tz)\in\big[\cos(t_jz)-\delta|z|,\ \cos(t_jz)+\delta|z|\big],\qquad\text{width}=2\delta\|Z\|=\varepsilon .$$

Count. $\Nb(\mathcal C)\le J\le2T\|Z\|/\varepsilon+1$; same for $\mathcal S$. Union: $\le2(2T\|Z\|+1)\varepsilon^{-1}$. (E), $V=1$: Donsker, so both parts converge jointly.

Limit. $\mathbb G(t)=\mathbb G\cos_t+i\,\mathbb G\sin_t$ with $$\E\big[\mathbb G(s)\overline{\mathbb G(t)}\big]=\E e^{i(s-t)Z}-\varphi(s)\overline{\varphi(t)}=\varphi(s-t)-\varphi(s)\varphi(-t).\ ∎$$

14

Mean absolute deviation

C

Let $m_2\lt\infty$. Show $\sqrt n(\Pn-P)|z-\theta|$ converges in $\ell^\infty([-1,1])$.

Kernel conditional cdf

AThm 1.20

Let $K$ be bounded and symmetric with compact support, $R(K)=\int K^2$, $h\to0$, $nh\to\infty$, $nh^5\to0$, $f_X(x)>0$. Assume $Y\mid X=z$ has density $\le c$ for $z$ near $x$, and that $z\mapsto F(t\mid z)f_X(z)$ and $f_X$ are $C^2$ near $x$ with second derivatives bounded uniformly in $t$. Prove $\sqrt{nh}\,(F^{(n)}(\cdot\mid x)-F(\cdot\mid x))\overset d\to\big(R(K)/f_X(x)\big)^{1/2}\mathbb B\circ F(\cdot\mid x)$.

Class. $F^{(n)}(t\mid x)=A_n(t)/A_n(\infty)$ with $A_n(t)=\frac1{nh}\sum_i\ind(Y_i\le t)K_i$, $K_i=K(\frac{X_i-x}h)$. Absorbing the rate: $$\sqrt{nh}\,(A_n(t)-\E A_n(t))=\Gn f_{n,t},\qquad f_{n,t}(y,z)=h^{-1/2}\ind(y\le t)K\big(\tfrac{z-x}h\big),\ t\in[-\infty,\infty].$$ The class depends on $n$ ⇒ Thm 1.20. Envelope $F_n=h^{-1/2}K(\frac{z-x}h)$.

(1.6) $\E F_n^2=\frac1h\int K^2(\frac{z-x}h)f_X(z)\,dz=\int K^2(v)f_X(x+hv)\,dv\to f_X(x)R(K)$.

(1.7) $F_n\le h^{-1/2}\|K\|_\infty\lt\eta\sqrt n$ as soon as $\eta\sqrt{nh}>\|K\|_\infty$, so $\E[F_n^2;F_n>\eta\sqrt n]=0$ eventually.

Partition. $Q_n(A)=\E[F_n^2\ind(Y\in A)]/\E F_n^2$ is a probability measure; (Q) with $\eta=\varepsilon^2$ gives $k\le2/\varepsilon^2$ cells. For $s,t\in[t_{j-1},t_j)$, $|f_{n,t}-f_{n,s}|=F_n\ind(s\wedge t\lt Y\le s\vee t)\le F_n\ind(t_{j-1}\lt Y\lt t_j)$, so $$\E\sup_{s,t}|f_{n,t}-f_{n,s}|^2\le\|F_n\|^2Q_n((t_{j-1},t_j))\le\varepsilon^2\|F_n\|^2 .$$

(1.9) $\int_0^{\delta_n}\sqrt{\log(2\varepsilon^{-2})}\,d\varepsilon\to0$ by (E).

(1.8) The partition depends on $n$, so check: for $s\lt t$, $$\E(f_{n,t}-f_{n,s})^2=\int K^2(v)P(s\lt Y\le t\mid X=x+hv)f_X(x+hv)\,dv\le c\,(t-s)\,\E F_n^2\to0$$ uniformly over $t-s\le\delta_n\to0$.

Covariance. $\E f_{n,s}f_{n,t}=\int K^2(v)F(s\wedge t\mid x+hv)f_X(x+hv)dv\to f_X(x)R(K)F(s\wedge t\mid x)$, and $\E f_{n,s}=h^{1/2}\int K(v)F(s\mid x+hv)f_X(x+hv)dv=O(h^{1/2})$. So $\sigma(s,t)=f_X(x)R(K)F(s\wedge t\mid x)$, and Thm 1.20 gives $\tilde X_n:=\Gn f_{n,\cdot}\overset d\to\mathbb G$ in $\ell^\infty([-\infty,\infty])$.

Ratio and bias. Write $F_t=F(t\mid x)$. Then $$\sqrt{nh}\,(F^{(n)}(t\mid x)-F_t)=\frac{\tilde X_n(t)-F_t\tilde X_n(\infty)+\sqrt{nh}\,b_n(t)}{A_n(\infty)},$$ with $b_n(t)=\E A_n(t)-F_t\E A_n(\infty)=\int K(v)[F(t\mid x+hv)-F_t]f_X(x+hv)\,dv=O(h^2)$ uniformly in $t$. This uses a Taylor expansion to second order, where the first-order term vanishes because $K$ is symmetric. So $\sqrt{nh}\,b_n=O(\sqrt{nh^5})\to0$. Also $A_n(\infty)=f^{(n)}(x)\overset P\to f_X(x)$ (Thm 2.1). Slutsky and the continuous mapping theorem give the limit $(\mathbb G(t)-F_t\mathbb G(\infty))/f_X(x)$ with covariance $$\frac{f_XR(K)\big[F_{s\wedge t}-F_tF_s-F_sF_t+F_sF_t\big]}{f_X^2}=\frac{R(K)}{f_X(x)}\big(F_{s\wedge t}-F_sF_t\big),$$ i.e. $(R(K)/f_X(x))^{1/2}\,\mathbb B\circ F(\cdot\mid x)$. ∎

AThm 1.21

Let $d=1$, $f_X(x)>0$ continuous at $x$, (i) $z\mapsto F(t\mid z)$ continuous at $x$ for all $t$, (ii) $\sup_t|F(t\mid z)-F(t\mid x)|\le L|z-x|$ near $x$, $\kappa\to\infty$, $\kappa^{3/2}/n\to0$.
